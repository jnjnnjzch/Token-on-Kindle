# Token on Kindle for KOReader

This plugin is designed for jailbroken Kindle devices running KOReader, including **Start KOReader (no framework)** mode.

It intentionally separates three different jobs that should not be confused:

1. **KOReader sleep screen** — KOReader itself displays `/mnt/us/token-on-kindle/dashboard.png` while KOReader is running.
2. **Kindle linkss mirror** — when `/mnt/us/linkss/screensavers` exists, the same image is mirrored to `bg_xsmall_ss00.png` for the native ScreenSavers Hack after Amazon's framework is running again.
3. **Updates while suspended** — a small shell helper, independent of `lab126_gui`, uses `com.lab126.powerd` RTC wakeups to briefly wake the Kindle, fetch a fresh image, repaint the active sleep screen with `eips`, and restore Wi-Fi if it had been off.

The helper does **not** install an Upstart job and does **not** use `start on started lab126_gui`. This matters because KOReader's no-framework launcher explicitly stops `lab126_gui`; the original Online Screen Saver Upstart service stops with it.

## Install

Copy the complete folder:

```text
tokenonkindle.koplugin
```

into:

```text
koreader/plugins/
```

Restart KOReader. The entry appears under the normal **More tools / Tools** area as:

```text
Token on Kindle
```

## First-time setup

1. Keep the desktop Token on Kindle application running.
2. Note its image URL, for example:

   ```text
   http://192.168.1.20:8765/dashboard.png
   ```

3. Open **Token on Kindle → Set dashboard URL**.
4. Save the URL. Background updates are enabled and the helper is started.
5. Choose **Update dashboard now** once to verify the connection.

A successful manual update also configures KOReader to use:

```text
screensaver_type = document_cover
screensaver_document_cover = /mnt/us/token-on-kindle/dashboard.png
```

The dashboard generated by Token on Kindle is 600×800, matching KT2/Kindle Basic 2014 native resolution.

## No-framework mode

KOReader's no-framework launcher stops Amazon's `lab126_gui`, but `powerd` remains available because KOReader itself uses it for suspend/resume.

The Token on Kindle helper therefore talks directly to the remaining Kindle services:

- `lipc-wait-event com.lab126.powerd readyToSuspend,wakeupFromSuspend,resuming`
- `com.lab126.powerd rtcWakeup`
- `com.lab126.cmd wirelessEnable`
- `com.lab126.wifid enable`
- `eips` for repainting the framebuffer while the device is still in Screen Saver state

The helper is launched from the KOReader plugin after KOReader has started. It is not a child service of `lab126_gui`, so no-framework mode does not automatically terminate it.

## Updates while asleep

When `powerd` announces `readyToSuspend`, the helper arms an RTC wakeup for the remaining update interval. At the scheduled wake it:

1. remembers whether Wi-Fi was off;
2. enables Wi-Fi when needed;
3. retries the local `dashboard.png` URL directly (it does **not** require Internet access or ping Google);
4. validates the PNG signature;
5. atomically replaces `/mnt/us/token-on-kindle/dashboard.png`;
6. mirrors it to linkss when that directory exists;
7. if `powerd` still reports `Screen Saver`, repaints the framebuffer with `eips`;
8. turns Wi-Fi back off when the helper was the component that enabled it.

KOReader distinguishes `WakeupFromSuspend` from `OutOfSS`, so an RTC wake is not treated by the helper as a user unlock.

## linkss

`linkss` is a mirror, not the active no-framework sleep-screen mechanism.

When present, the helper writes:

```text
/mnt/us/linkss/screensavers/bg_xsmall_ss00.png
```

This is useful after exiting KOReader, when the Amazon framework is restarted and the native ScreenSavers Hack owns the sleep screen again.

## Files

Runtime state is deliberately kept outside the plugin directory:

```text
/mnt/us/token-on-kindle/dashboard.png
/mnt/us/token-on-kindle/config.sh
/tmp/token-on-kindle-helper.pid
/tmp/token-on-kindle-helper.log
```

The fixed dashboard path lets KOReader, the sleep helper, and linkss all consume the same last known-good image.

## Troubleshooting

Use **Token on Kindle → Status** to see the configured URL, helper state, KOReader screensaver support, and linkss availability.

For background-update failures inspect:

```text
/tmp/token-on-kindle-helper.log
```

The plugin never installs or modifies `/etc/upstart`, never depends on the original Online Screen Saver extension, and does not need Amazon's framework to remain running while KOReader is active.
