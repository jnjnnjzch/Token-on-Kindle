# 火山方舟多路径诊断

此诊断器用于比较 Token on Kindle 在火山方舟 Agent Plan 企业版页面上的四条数据链路，不替代正式采集器。

## 0.9.7 当前正式链路

- AFP：读取“近 5 小时 / 近一周 / 近一月”三张页面卡片。
- 模型 Token：读取 ReactECharts / ECharts 实例的 `option`，再解析 `series` 或 `dataset`。
- 后台刷新：保留当前企业版 SPA 页面，在页面内触发查询或同步。

## 构建命令

```bash
npm run check:volcengine-debug
npm run debug:volcengine
```

需要生成安装包时使用：

```bash
npm run build:volcengine-debug
```

普通的 `npm run dev` 和 `npm run build` 不包含诊断探针；只有上述显式诊断命令会先重新生成正式 extractor，再附加调试模块。

## 诊断链路

1. **DOM**：独立读取三张 AFP 卡片。
2. **ECharts**：独立读取图表实例和模型序列。
3. **被动网络捕获**：包装页面的 `fetch` 与 XHR，按 JSON 字段结构识别 AFP、席位和模型用量响应。
4. **安全重放**：只重放 GET/HEAD，或明确看起来是 Get/List/Query/Usage/Stat 等只读查询的 POST 请求；包含 Create/Update/Delete/Subscribe/Reset 等动作的请求不会重放。
5. **页面查询触发**：点击企业版用量区域中的“查询/刷新”按钮，让网页自己发出请求。

## 使用方法

1. 运行诊断构建的桌面程序。
2. 打开“火山方舟”卡片并完成网页登录。
3. 点击注入工具栏中的“开启火山诊断”；页面会刷新一次，以便诊断器从文档初始化阶段安装网络钩子。
4. 保持在 Agent Plan 企业版用量页面，等待卡片和模型图表加载。
5. 点击“打开诊断面板”。
6. 点击“运行全部”。
7. 点击“复制报告”，将 JSON 报告用于分析。
8. 完成后点击“关闭火山诊断”，恢复完全休眠状态。

“只读比较”不会点击页面查询按钮，也不会重放请求，只比较当前 DOM、ECharts 和已经捕获到的网络结果。

## 隐私与资源限制

诊断器不会把以下内容写入报告：

- Cookie；
- Authorization 值；
- AccessKey / SecretKey；
- 会话令牌、CSRF 值；
- 完整网络响应。

报告只保留：

- 脱敏后的域名、路径和少量查询参数；
- 请求方法、请求头名称、请求体字段路径；
- 响应字段路径、相关数值和结构评分；
- DOM/ECharts 读取结果。

网络记录最多保留 60 条，安全重放模板最多保留 20 条，且都只存在于当前 WebView 内存中；导出的报告不包含私有重放模板。

## 判断标准

- 网络响应能稳定识别 AFP 和模型数据：下一步应将网络登录态直读提升为正式主路径。
- 只能识别 AFP：可先用网络读取额度，模型继续使用 ECharts。
- 网络响应结构稳定但重放失败：保留被动捕获，刷新时由页面按钮触发请求。
- 网络没有相关响应：继续使用 0.9.7 的 DOM + ECharts 路径，并根据报告检查是否存在 Service Worker、iframe 或更早的请求阶段。
