# v0.2 设计说明

## Kindle 画面

- 600×800，8 位灰度 PNG。
- Codex 使用一条高对比度周额度进度条。
- DeepSeek 只显示结构化数值，不绘制网页原始提示文字。
- V4 Flash 与 V4 Pro 各自显示当日 Token、费用、缓存率和相对用量条。
- “今日构成”使用两组灰阶柱状图比较 Flash / Pro 的 Token 与费用。
- 底部 80 像素为纯黑安全区，供 Kindle 固件叠加白色“滑动以解锁”。

## 后台更新

桌面端启动时创建两个独立、持久的系统 WebView：

- `codex-login`
- `deepseek-login`

关闭这些窗口只会隐藏，不会销毁。Rust 原生线程每 10 分钟让两个页面重新加载；页面完成渲染后，注入脚本重新读取当前用量并发回主窗口。整个流程使用网页登录态，不要求 DeepSeek `sk-...` API Key。

## DeepSeek 数据来源

优先从页面已经渲染的官方 Usage 组件读取：

- `data-usage-layout-card`：余额、区间费用、请求数与 Token 总数。
- ECharts 费用图：当日 Flash / Pro 费用。
- Flash / Pro Token 图：当日缓存命中、缓存未命中和输出 Token。
- 当 ECharts 实例不可直接访问时，脚本通过模拟悬停读取页面自身的 tooltip。

不主动请求 DeepSeek 公共 API，也不复制或导出 Cookie。
