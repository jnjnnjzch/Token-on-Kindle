# v0.8.4

## 火山方舟模型 Token：直接读取网页图表

- 不再监听或筛选火山控制台的网络请求。
- 精确定位 Agent Plan 企业版中的“模型调用明细”区域。
- 直接读取页面使用的 `echarts-for-react` 组件：优先使用页面暴露的 ECharts 实例；全局 ECharts 不可见时，从 React 组件实例调用 `getEchartsInstance()`；组件实例暂未就绪时读取其 `option` 属性。
- 从当前图表的 `series` 或 `dataset` 中，按页面图例识别任意数量的模型，并汇总当前日期范围内的 Token。
- 模型名称不再硬编码，新增或减少模型时自动适配。
- 页面载入后分阶段重试；AFP 先就绪、模型图表稍后载入时会再次自动同步。
- 右下角状态明确显示本次同步读到的模型数量。

## 诊断

火山方舟诊断 JSON 现在保留：

- `models`：模型名称、当前范围总 Token、最新点、峰值和数据点数量；
- `modelUsage`：读取来源、开始/结束日期和“天/小时”粒度；
- `modelChart`：图表数量、ECharts 实例 ID、访问方式、图例模型、series/dataset 数量和解析模式。

这让“图表未就绪”“拿不到 ReactECharts 实例”“图表结构没有数据”能够被明确区分，而不是只显示 AFP 成功。

## 构建验证

Rust 构建脚本会在嵌入采集器之前检查直接图表读取标记，并拒绝包含旧火山网络拦截调用的构建。Windows 验证 EXE 也会再次检查内嵌脚本，确保发布工件与通过测试的源码一致。
